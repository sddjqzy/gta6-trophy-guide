A complete Grand Theft Auto VI trophy guide for PS5: all 55 trophies — 1 platinum, 2 gold, 6 silver and 46 bronze — each with a plain-English guide, a five-stage platinum roadmap, the one missable trophy flagged before you can lose it, and a checklist tracker that saves your progress in the browser, with spoiler-free mode, grade and kind filters, and checklist export and import.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 to try it in desktop Chrome.
