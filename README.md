The best GTA 6 trophy guide — all 55 trophies with a tracker. Each trophy has a full guide with sources, so you can track your progress and find how to unlock every one. A static web app: no build step, no network at run time.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 to try it in desktop Chrome.
